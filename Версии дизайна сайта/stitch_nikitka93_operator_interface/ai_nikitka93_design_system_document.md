# AI_Nikitka93 Design System

## Product Identity
- **Name:** AI_Nikitka93
- **Concept:** Premium terminal / CLI operator console.
- **Tone:** Serious, research-focused, structured, factual.

## Language Support
- **Primary:** Russian (RU)
- **Secondary:** English (EN)
- **Mechanism:** Explicit RU / EN switch in the header. Full localization for all interface text.

## Visual Style
- **Base Style:** Terminal / CLI interface.
- **Aesthetic:** High-end operator console, monospace-led, structured system prompts.
- **Avoid:** "Hacker" parodies; focus on professional system architecture.

## Color Palette
- **Terminal Base:** `#0A0E0A` (Deep black-green)
- **Primary Phosphor:** `#32CD32` / `#4AF626` (Phosphor-lime)
- **Archive Bone:** `#E5E4D2` (Off-white for text/data)
- **Metal / Hardware:** `#565E5E` (Titanium)
- **Alert / Warning:** `#FF4500` (Ember orange)

## Typography
- **Dominant:** IBM Plex Mono (for data, logs, and primary UI)
- **Emphasis:** Space Grotesk (for headers or selective visual weight)

## Components
- **Command Surface:** Structured headers with system status and locale switch.
- **System Aliases:** Identity split shown as verified sources.
- **Query Results:** Archive entries formatted like database returns.
- **Log Views:** Detailed records with metadata rows and evidence blocks.
- **Command Syntax:** Navigation and links styled as CLI commands.
