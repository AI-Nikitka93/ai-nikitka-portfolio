# Design System: AI_Nikitka93 Portfolio

**Project:** AI_Nikitka93 Portfolio
**Style:** Immersive 3D spatial interface, deep black-green atmosphere, cinematic, authored, experimental.
**Localization:** 
- Primary: Russian (Default)
- Secondary: English (via header switch)
- Logic: Entire interface changes language consistently. Never mix languages.

## Visual DNA
- **Atmosphere:** Void-like, room-like depth, layered planes.
- **Aesthetic:** High-contrast, tactical, experimental, non-SaaS.

## Typography
- **Display:** Space Grotesk
- **Metadata/Labels/IDs:** IBM Plex Mono

## Color Palette
- **Void Black:** #0A0D0C (Primary Background)
- **Carbon Fog:** #161B19 (Layered Surfaces / Secondary Background)
- **Phosphor Lime:** #B7FF3C (Primary Accent / Tactical Highlights)
- **Archive Bone:** #D6CFBF (Secondary Text / Neutral Accents)
- **Ember Orange:** #FF6A2A (Alerts / Critical Metadata)
- **Raw Titanium:** #8E968C (Tertiary Text / Dimmed Metadata)

## Core Components
- **Identity Split:** Visual distinction between 'AI_Nikitka93' (Operator) and 'Никита Кизевич' (Human Source).
- **Spatial Evidence Modules:** Dossier cards with 3D depth, tactical borders, and mono-spaced data.
- **System Console:** AI assistant interface embedded into the environment.
