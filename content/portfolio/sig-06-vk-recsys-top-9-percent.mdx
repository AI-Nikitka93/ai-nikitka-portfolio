## Суть задачи и метод

В рамках соревнований **VK RecSys Challenge** требовалось решить проблему «холодного старта» для рекомендательной системы коротких клипов VK. Главной сложностью было точное предсказание предпочтений пользователей на основе крайне ограниченного объема данных об их первых взаимодействиях.

Вместо традиционного ручного написания кода ML-модели, весь процесс был выстроен через **чистый промпт-инжиниринг (Pure Prompting)**:
1. Исходная математическая постановка задачи и описание API передавались в модель **Gemini 2.5/3.0**.
2. Нейросеть генерировала, отлаживала и оптимизировала Python-скрипты для обучения и инференса.
3. Логи выполнения, сообщения об ошибках сборщика и промежуточные метрики качества отправлялись обратно в LLM.
4. Шаг за шагом модель дорабатывала архитектуру признаков и гиперпараметры модели.

## Результаты

Благодаря эффективному управлению контекстом и логикой сборки кода, готовое решение вошло в **TOP-9% лучших в мире** (68-е место из 796 зарегистрированных участников). Это доказало, что промпт-ориентированный подход позволяет успешно конкурировать с опытными Data Science специалистами на реальных соревновательных датасетах без ручного написания кода.
