# Pattern Matrix

| Pattern | Use | Implementation |
|---|---|---|
| Artist roster first | Directly communicates the four catalog lanes | Hero release map and `#artists` panels |
| Dense discography explorer | Needed because there are 20+ releases | Search, artist filters, release cards, tracklists |
| Archive/index visual language | Fits a fast-growing catalog better than a single-artist fan site | Timeline and structured metadata |
| Custom cover placeholders | Real artwork was not present locally | Code-generated cover marks per artist |
| No fake proof | Catalog has real metadata but no verified public links in local sources | Publication status block states what remains |
| Mobile-first controls | Portfolio will likely be checked from phone | Single-column layout, full-width filter buttons under 560px |

## Negative Pattern Rejected

Dark hero + huge text + glowing abstract music object + three feature cards.

Reason: it would not prove the catalog, would not separate artists, and would look like a generic AI template.
