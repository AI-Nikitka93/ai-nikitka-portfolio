# Direction Options

## 1. Safe Premium

Minimal label site: restrained black/white typography, artist rows, album cards, no strong art direction.

Verdict: rejected. Clear, but too close to generic label templates and not memorable enough for four AI-artist lanes.

## 2. Signature

Catalog archive / release map: first viewport behaves like a label index, with four artist lanes, release spines, handcrafted cover marks and dense metadata.

Verdict: selected. It uses real project structure, avoids fake media claims and scales as the catalog grows.

## 3. Experimental

Interactive audio-visual canvas with animated waveform/album constellations.

Verdict: deferred. Stronger for a future v2, but needs either real audio snippets, approved cover art, or a scoped `INTERACTIVE` job to avoid decorative motion.

## Selected Direction

`Signature catalog archive`.

First-viewport object: release map with artist lanes and album spines.

Signature mechanic: filterable discography plus spotlight and chronological release map.

Asset route: handcrafted HTML/CSS cover system now; future real covers through `IMAGEN` / `ComfyUI` or imported distributor artwork after approval.
