## Decisions Implemented

1. First viewport shows four artist lanes and release spines immediately, avoiding a generic music hero.
2. Catalog is filter/search-first because the project already has many releases and four distinct artist identities.
3. No fake streaming links, fake metrics, fake testimonials or placeholder press claims.
4. Custom generated-by-code cover graphics stand in for unprovided real artwork.
5. Mobile layout collapses to a clear single-column catalog with 44px+ controls.
