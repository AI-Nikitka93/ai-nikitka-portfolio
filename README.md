# AI Nikitka93 Music Portfolio

Локальная статическая витрина артистов и релизов проекта.

## Открыть

Откройте файл:

```text
M:\Проекты промты\Музыка\portfolio-site\index.html
```

Сайт работает без сборки и без внешних зависимостей.

## Структура

- `index.html` - страница.
- `styles.css` - визуальная система и responsive layout.
- `site-data.js` - структурированные данные артистов, релизов и треклистов.
- `app.js` - фильтры, поиск, spotlight и таймлайн.
- `docs/` - минимальная evidence/design-папка для будущего обновления.

## Перед публичной версией

1. Добавить реальные streaming / Band.link / DSP URL.
2. Добавить утвержденные обложки или отдельный image/video asset pass.
3. Добавить контакты для press kit / лицензирования.
4. Повторно проверить мобильный layout после добавления реальных изображений.
